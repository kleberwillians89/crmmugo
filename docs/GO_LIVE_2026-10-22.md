## Passo a passo (na ordem)

### 1. Secrets das Edge Functions
Supabase → Project Settings → Edge Functions → Secrets (ou `supabase secrets set NOME=valor`):

| Secret | Para quê | Obrigatório |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude no atendimento e na prospecção (console.anthropic.com). **Sem ela, o sistema usa o GPT** (`OPENAI_API_KEY` + `OPENAI_MODEL`, que já existem) | Não |
| `ANTHROPIC_MODEL` | Opcional. Padrão `claude-sonnet-5-5` | Não |
| `AI_PROVIDER` | Opcional. `openai` para voltar à OpenAI | Não |
| `OPENAI_API_KEY` / `OPENAI_MODEL` | Já existem. Usados quando não há chave do Claude, e sempre para **transcrever áudio** | Sim (enquanto não houver Claude) |
| `PROSPECTING_WORKER_KEY` | Senha do cron da prospecção (gere um valor aleatório longo) | Sim |
| `EMAIL_WORKER_KEY` | Senha do cron do e-mail marketing (valor aleatório) | Sim |
| `GMAIL_SERVICE_ACCOUNT_JSON` | JSON da conta de serviço do Google (passo 5) | Para e-mail frio |
| `GMAIL_SENDER` | Caixa do domínio secundário, ex. `kleber@seudominio2.com.br` | Para e-mail frio |
| `RESEND_API_KEY` | Resend → API Keys | Para newsletter |
| `RESEND_WEBHOOK_SECRET` | Resend → Webhooks (começa com `whsec_`) | Para métricas |
| `EMAIL_FROM` | Remetente padrão, ex. `Mugô <news@seudominio.com.br>` | Para newsletter |

`COMMERCIAL_AI_WORKER_KEY`, `META_ACCESS_TOKEN`, `SUPABASE_*` já existem.

### 5. Gmail do domínio secundário (e-mail frio)
1. Google Workspace no domínio novo, com a caixa que vai enviar.
2. DNS do domínio: SPF, DKIM (Admin Google → Apps → Gmail → Autenticar e-mail) e DMARC (`v=DMARC1; p=none; rua=mailto:...`).
3. **Aquecimento: 2–3 semanas** usando a caixa normalmente antes de ligar o envio.
4. console.cloud.google.com → novo projeto → ativar **Gmail API** → Contas de serviço → criar → Chaves → JSON. Esse JSON vai no secret `GMAIL_SERVICE_ACCOUNT_JSON`.
5. admin.google.com → Segurança → Controle de API → **Delegação em todo o domínio** → adicionar o *Client ID* da conta de serviço com os escopos:
   `https://www.googleapis.com/auth/gmail.send,https://www.googleapis.com/auth/gmail.readonly`
6. No CRM: Prospecção → Configuração → remetente igual ao `GMAIL_SENDER`, limite diário baixo (10–15) e “Envio de e-mail ligado” só depois do aquecimento.

### 6. Resend (newsletter)
1. Resend → Domains → adicionar e verificar o domínio/subdomínio da newsletter (ex.: `news.seudominio.com.br`).
2. Webhooks → endpoint `https://<projeto>.supabase.co/functions/v1/resend-webhook`, eventos `email.delivered, email.opened, email.clicked, email.bounced, email.complained`. Copie o signing secret para `RESEND_WEBHOOK_SECRET`.
3. No CRM: E-mail marketing → Contatos → **Importar do CRM**.
4. ⚠️ O Resend proíbe prospecção fria e listas compradas. Prospects só entram na base de e-mail marketing depois de responderem (o sistema já faz isso).

### 7. Ligar o atendimento
1. Configurações → **Base da IA**: preencha pelo menos *Sobre a Mugô*, *Serviços* e *O que a IA não pode dizer*; cases e FAQ ajudam muito.
2. Coloque o link de agenda.
3. Modo **Copiloto** por 1–2 semanas: a sugestão aparece acima do campo de mensagem na Caixa de entrada → “Usar” → revisar → enviar.
4. Quando as sugestões estiverem boas, mude para **Automática**.

## Checklist de teste
- [ ] Menu mostra 5 áreas; abas trocam de página; URL antiga (ex. `/financeiro/dividas`) abre no Financeiro.
- [ ] Usuário não-admin não vê Configurações → Avançado.
- [ ] Copiloto: mandar 3 mensagens seguidas de um número de teste → aparece **uma** sugestão em ~10s.
- [ ] Áudio de teste → texto `[áudio] …` aparece no histórico e a sugestão responde ao conteúdo.
- [ ] Automática: resposta chega com “digitando…” antes; pedir preço fora da base → IA diz que confirma com o time.
- [ ] Prospecção: importar CSV com 3 linhas → Pesquisar → nota, e-mail e follow-ups preenchidos; “Enviar teste para mim” chega na caixa do domínio secundário.
- [ ] Responder o e-mail de teste a partir de outra conta → em até 5 min o prospect vira “Respondeu” e aparece no Funil com tarefa.
- [ ] Newsletter: campanha de teste para 2 e-mails internos; clicar em “Descadastrar” → contato fica descadastrado.
